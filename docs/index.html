视觉定位：让程序「看懂」界面

WeChat聊天列表是自绘 UI，系统无障碍接口拿不到列表元素，只能靠视觉。T1 用 OpenCV 规则 + OCR 识别，T2 升级 YOLOv8 微调，直接输出精确 bounding box，不再依赖任何写死坐标。

  • 1检测红点 / 徽标 / 头像 / 导航图标 / 标题栏五类元素
  • 2标题栏被识别后即可排除 no-fly zone，杜绝双击最大化
  • 3ONNX 导出后 CPU 数十 ms 一帧，不吃 GPU
已落地

T1 · 规则增强 OCR

微信聊天列表是 CEF 自绘界面，系统无障碍接口读不到任何元素，未读状态只能靠"看截图"。T1 用一套规则增强的 OCR 管线把这件事做扎实：四路图像预处理融合 + 已知布局快通道 + 数字置信门槛，把"看没看准"和"看不看得稳"两个难题一起解掉。

  • 四路预处理融合：灰度 / 反相 / Otsu / CLAHE 各跑一遍 RapidOCR 取最稳结果，弱光、头像遮挡下照样认得准
  • 数字置信门槛 score≥0.70：挡掉把 "8" 读成 "3" 的假数字，未读数不再误报
  • 动态定位替代写死比例：用头像底边实时反推坐标，消除 0.115 固定比例在跨分辨率 / 换机器时的整列错位
规划中

T2 · YOLOv8 视觉定位

T2 升级到神经网络视觉定位：用社区标注的真实帧微调 yolov8n，让模型直接"框出"聊天项、头像、红点，输出像素级 bounding box。彻底摆脱对写死坐标的依赖，定位精度随模型迭代持续收敛。

  • 像素级视觉定位：端到端输出 bounding box，跨分辨率 / 跨皮肤 / 跨机型天然鲁棒
  • 本地一键切换：localization_mode（rule_based / yolo）开关，yolo 不可用时无缝回退规则，体验不中断
  • 开放共建：已落地 yolo_locator.py + prep_yolo_labels.py，社区可贡献标注集，模型越用越准
