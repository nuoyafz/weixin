怎么更换 / 新增下载地址？（给方哥看的）

下载地址全部写在本文件底部的 DOWNLOADS 数组里，改这一个地方就行，不用再开别的文件。

  1. 用记事本 / VS Code 打开 download.html。
  2. 换链接：直接改某条的 url: 值，保存刷新页面即可生效。
  3. 加一条：复制下面任意一整块 { ... }，用逗号隔开放进数组。
// 新增一条就这么写，别忘了前面加逗号
,{
  name: "VisReply 直链",
  version: "v1.7.1",
  date: "2026-09-11",
  platform: "windows",
  desc: "服务器直链，不限速",
  url: "https://你的域名/VisReply_Setup.exe",
  btn: "本地下载"
}

字段：name 名称 · version 版本 · date 日期 · platform 图标(windows/mac/linux) · desc 描述 · url 地址 · btn 按钮文字 · primary:true 设为主推高亮。
