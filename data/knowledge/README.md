# My WeChat Agent - 知识库目录

在此目录下放置知识库文件，支持以下格式：
- .txt - 纯文本
- .md - Markdown
- .json - JSON
- .csv - CSV

## 示例

### 产品介绍.txt
```
我们的产品是一款专业的微信客服助手，可以帮助您自动化处理客户消息...
```

### 常见问题.md
```
# 常见问题

## Q: 如何启动助手？
A: 点击界面上的"启动助手"按钮即可...

## Q: 支持哪些大模型？
A: 支持所有OpenAI兼容格式的大语言模型...
```

## 使用说明

1. 将知识库文件放入此目录
2. 系统启动时会自动加载所有文件
3. 文件会被自动分块并建立索引
4. 对话时会自动检索相关内容作为上下文
